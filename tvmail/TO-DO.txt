What tvmail does not do yet. Defects live in BUGS.md, not here; what it does
today is in README.md. The numbers are stable (code and notes refer to them),
so finished items are gone and the gaps stay.

Done: 1-10, 13, 16 and 23 - attachment browser, forward, reply all and Bcc,
mark unread, purge, move to folder, Window list, type-to-filter, column sort,
folder counts, mark-read only after you look, save as .eml, out of office.

Classic TUI polish
11 Status-line context - when focus is in Folders vs Messages vs a compose
   window, swap the F-keys (e.g. Enter = Edit draft only in Drafts).
12 Mouse - tvision already supports it; click-to-focus panes and double-click
   to open would make the cyan desktop feel finished.

Behaviour that would make it feel "done"
14 Periodic pull - an idle timer calling the existing background pull, with a
   quiet "N new" on the status line instead of a blocking message box every
   time. (The folder counts are the first half of it.)
15 tvmailrc - colours, default folder, poll-on-start, list date format,
   HTML-vs-plain preference. Keeps ~/.mailrc for mail(1) and puts tvmail-only
   knobs somewhere else.
17 Address-book write path - F4 is read-only aliases today. Add/edit alias
   lines in ~/.mailrc so the book is not a one-way dump into To:.
18 Pipe the body through $PAGER / less or an external $EDITOR - an escape
   hatch for huge mail and for people who still want vi for a long reply.

Worth doing later (higher design cost)
19 Threading - useful, but it fights mbox + IMAP UID indexing and the current
   one-line list. Filter + sort get you 80% of the way on a small store.
20 HTML mail as a second view - the backend already has an HTML fallback; a
   "view HTML as text" toggle is enough. A real renderer is out of character.
21 Multi-select - space-tag then delete/move/mark, like Midnight Commander.
   Purge and Move to... already give bulk action without it.
22 Resizable split - drag or +/- on the folder width and the list/body ratio.
   The layout is a fixed 22-column / 2:5 split.

A short order for what stays in character: periodic pull (14), then tvmailrc
(15), the status-line context swap (11) and mouse manners (12), then the
address-book write path (17). That uses code that exists and does not turn
tvmail into mutt.

Setup and integration
24 Edit the config in the app - a window for tvmail.conf (mode, IMAP / SMTP
   hosts, folders, signatures) with a Verify (parse it, then log in to the
   IMAP and SMTP servers without touching mail) and a Reload that applies it to
   the running backend. Passwords stay out of the file. tvchat wants the same
   (tvchat/TO-DO.txt 13): share it in tvcommon.
25 tvmail and tvchat talking to each other - OPTIONAL (tvchat/TO-DO.txt 12).
   Done (Oct 25): Message > Chat with sender and Open chat invite, and tvchat's
   Invite mailing the link through tvmail's account. Still to do: tvmail starting
   a compose window when tvchat asks to "write an email to this contact".
